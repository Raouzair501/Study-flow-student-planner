# StudyFlow — Student Productivity Planner

A simple, responsive student productivity planner designed to help students organize tasks and manage focused study sessions.

**Live Demo:** [Open StudyFlow](https://raouzair501.github.io/Study-flow-student-planner/)

## Features

- Add tasks with High, Medium, and Low priorities
- Mark tasks as completed
- Filter tasks by status
- Delete tasks and clear completed items
- Focus and break timer
- Timer state and tasks saved in browser local storage
- Responsive interface for different screen sizes

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## Getting Started

1. Open the live demo using the link above, or clone this repository.
2. If working locally, open `index.html` in your browser.
3. Add tasks, choose priorities, and start a focus session.
