# StudyFlow — Student Productivity Planner

StudyFlow is a responsive, browser-based planner for students. It helps users organize tasks, track completion, and run a simple focus timer.

## Features

- Add tasks with High, Medium, or Low priority
- Mark tasks complete or delete them
- Filter tasks by all, to-do, and completed
- Save tasks in browser local storage
- View task and completion counts
- Use a 25-minute focus timer or 5-minute break timer
- Rotate through short study reminders
- Responsive layout for desktop and mobile
- Built with plain HTML, CSS, and JavaScript; no framework or installation required

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a modern browser.

For a local development server, you can also use the VS Code **Live Server** extension.

## Project structure

- `index.html` — page structure and interface
- `style.css` — layout, colours, and responsive styling
- `script.js` — task management, local storage, filters, and timer logic

## Notes

Tasks are saved in the current browser using `localStorage`. They are not synced between devices or browsers. This project does not send task data to a server.
